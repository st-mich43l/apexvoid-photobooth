# Windows release plan

Status: **not production-ready**. UX6-1 runtime hardening, UX6-2/3/4 validation tooling and diagnostics, and initial UX6-7/9 localization and packaging work are merged in PRs #39–#41. Ownership ordering, audit and artifact-policy corrections, and fail-closed recovery are merged in PRs #43–#45. PR #46 expanded localization across core operator views; PR #47 covered camera, printer and Gallery workflows; PR #48 covered frame management and the Frame Builder. Remaining dynamic driver messages are not translated, and Vietnamese text still needs target-display verification. Physical hardware acceptance, actual WebView2 kiosk testing, trusted signing and target filesystem qualification block production release. Do not label CI artifacts as production releases.

The Windows CI artifact contains one unsigned executable with pinned FFmpeg and Canon EDSDK DLLs embedded. Trusted master CI records its build version and executable SHA-256 in the job summary and validates the same executable on a camera-free Windows runner. GitHub wraps the one-file artifact in a ZIP. Use the download only after the entire workflow succeeds; pull-request workflows do not receive the vault password or publish the portable build. These records identify a build; they do not prove bit-for-bit reproducibility or publisher identity.

An eventual signed release must use a trusted code-signing identity held in an approved signing service or protected CI secret; never commit a certificate private key or password. Verify signatures with Windows `Get-AuthenticodeSignature` and publish verified checksums over a trusted channel. Do not disable SmartScreen or other Windows security to distribute unsigned executables.

Before release, complete the hardware and WebView2 matrices in `UX6_WINDOWS_ACCEPTANCE.md`, run endurance and crash-recovery scenarios, qualify offline WebView2 installation, establish reproducible clean builds, review third-party licenses, test backup/restore and upgrade on copies, and publish versioned release notes and checksums. The per-user installer definition remains in the source tree but is not included in the single-file CI artifact.
