# ApexVoid Photobooth 0.2.0

The first public release of ApexVoid Photobooth: a local-first photobooth application for Windows 10 and 11 (x64),
delivered as one portable executable. No installer, account, server or internet connection is needed.

## What it does

- **Guest sessions:** frame selection, live preview, countdown, capture, review, individual retakes and a fullscreen
  Booth Mode.
- **Cameras:** Canon EDSDK integration for compatible EOS cameras (the Canon EDSDK is embedded in this build), Windows
  webcam capture through FFmpeg (built in), and a clearly labelled simulated camera for trying the workflow.
- **Frames and printing:** built-in layouts, a frame builder, custom PNG frames, 300/600 DPI composition, Windows
  printer setup, print history and reprints.
- **Media library:** local SQLite metadata and files, session browsing and search, editing, session ZIP export,
  recoverable trash.
- **Operator tools:** setup and readiness checks, English and Vietnamese interfaces, offline support diagnostics,
  library backup and recovery guidance.

## Requirements

- Windows 10 or 11, 64-bit (x64)
- Microsoft Edge WebView2 Evergreen Runtime (the application checks for it and explains how to install it)

## Before you rely on it

- **Hardware has not been physically verified by the project.** Camera, printer and touchscreen support is software
  integration tested in CI with simulated devices; the hardware acceptance procedures in `docs/HARDWARE_TESTS.md` are
  still open. Test with your own equipment before an event.
- **Not code-signed.** Windows SmartScreen may warn on first run. Check the SHA-256 in `SHA256SUMS` before running it.
- Photos, sessions and settings stay on the PC (`Documents\apexvoid-studio` and `%APPDATA%\ApexVoidPhotobooth`). You are
  responsible for how guest photos are stored, shared and deleted.
